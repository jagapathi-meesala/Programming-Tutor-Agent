# Code Explanation

## Inputs
Source code and a language identifier.

## Behavior
Inspect imports, definitions, control-flow statements, and basic structure without executing the source.

## Outputs
Return a structured explanation with static observations and an explicit execution limitation.

## Invalid Inputs
Reject missing, wrong-type, or empty code input.
