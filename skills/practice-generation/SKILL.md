# Practice Generation

## Inputs
Topic, programming language, and one of beginner, intermediate, or advanced.

## Behavior
Select a deterministic exercise template and produce a coding task plus testing task.

## Outputs
Return the requested topic, language, difficulty, and exercises.

## Invalid Inputs
Reject missing fields, empty topic/language, or unsupported difficulty.
