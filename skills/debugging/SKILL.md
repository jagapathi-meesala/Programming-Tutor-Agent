# Debugging

## Inputs
Source code and language.

## Behavior
Apply only the implemented static rules and attach source evidence to every finding.

## Outputs
Return rule IDs, line numbers, evidence, messages, and suggestions.

## Invalid Inputs
Reject missing, wrong-type, or empty code input.
